# Home security system using stm32 

## Description

PEECT525 ARM Architecture, Programming and Interfacing course project for B.tech Electronics and Communication Engineering @ College of Engineering Trivandrum (CET)
Done by Team  (Akul S Mohan, Riya Anna Thomas, Rugma L Satheesh, Samil R, Muhammad Farseen K)

## About
A Hardware based Home security system built on stm32. Further details to be added

## Components 

- Transmitter
  * 1x STM32F411CEU6 Black pill board
  * 1x 16x2 LCD display
  * 1x 4x4 Matrix keypad
  * 1x sg90 Servo Motor
  * 1x Buzzer
  * 1x PIR sensor

- Miscellaneous
  * Jumper Wires
  * Breadboard
  * Capacitors
  * Resistors
  * Single core wire
  * Proto-board
